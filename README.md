# 校园实验田环境监测系统
C语言实训项目，基于链表实现多实验田温湿度采集、数据统计、异常告警全流程管理，采用模块化分层开发。

## 一、项目整体架构
分层模块化代码，共6大模块：
1. 通用工具层：屏幕清屏、菜单分隔线、内存链表释放、时间字符串转换工具
2. 系统核心层：系统初始化/销毁、田块数组自动扩容、全局内存管理
3. 实验田管理层：田块增删查搜、数组扩容、关联记录/告警级联清理
4. 传感器记录层：记录增删、多维度展示、过期数据清理、均值计算
5. 数据分析层：异常记录筛选、温湿度极值查询、时序趋势分析
6. 告警管理层：单条异常告警、连续多条异常告警、告警排序、告警处理统计

## 二、完整功能清单
### 1. 实验田管理
- 添加自定义实验田（名称、负责人、默认3台传感器）
- 批量展示全部田块信息
- 根据ID精准查询田块
- 按名称模糊检索田块
- 按负责人模糊检索田块
- 删除田块：级联删除该田块全部传感器记录、全部关联告警，自动前移填充数组空缺

### 2. 传感器记录管理
- 手动录入温湿度数据，自动判断是否异常并标记
- 展示指定田块最新N条记录（时间倒序）
- 展示指定田块全部历史监测记录
- 批量删除N天前过期历史记录
- 统计单块田总记录条数
- 计算单块田全部记录平均温度

### 3. 数据统计与分析
- 筛选并打印所有异常记录，标注异常类型（温度过高/过低、湿度过高/过低）
- 统计单田温湿度历史最大值、最小值及对应采集时间
- 时序趋势分析：对比首尾数据判断温湿度上升/下降/平稳，附带字符可视化图表

### 4. 告警管理系统
#### 告警类型
1. 环境参数异常告警：单条记录温湿度超标触发
   - 湿度异常：一级告警 ALERT_LEVEL_1
   - 温度超标：二级告警 ALERT_LEVEL_2
2. 持续环境异常告警：同一田连续3条及以上异常，自动生成三级最高告警 ALERT_LEVEL_3

#### 告警功能
- 批量扫描历史异常记录自动生成对应告警
- 单独查询某块田所有持续异常告警
- 全局展示全部告警（支持多维度排序）
- 按田块+告警类型批量处理（删除）已解决告警
- 统计单块田所有告警总条数

## 三、本次迭代全部修复内容（fix汇总）
### 1. 编译安全问题修复
1. 补全全部 `strcpy_s / strcat_s` 缓冲区长度 `sizeof()` 参数，消除VS安全字符串编译报错
2. 统一所有内存分配失败打印提示为中文，删除英文报错文本
3. 删除 `create_monitor_system` 无效冗余代码 `sys=sys;`
4. 修复内存分配失败分支缺少return，防止野指针、空指针崩溃

### 2. 核心业务逻辑BUG修复
1. delete_field 致命缺陷：原代码清空全系统所有记录告警 → 修改为仅级联删除当前田关联数据
2. find_abnormal_records 硬编码阈值 10/35/40/85 替换全局宏 TEMP_MIN / TEMP_MAX / HUMI_MIN / HUMI_MAX
3. analyze_trend 魔法数字0.5f删除局部常量，统一使用全局宏 TREND_CHANGE_THRESHOLD
4. 修复传感器记录排序条件写反问题，保证输出为**最新记录置顶**时间倒序
5. 修复持续异常告警重复生成漏洞，增加重复告警判断逻辑，避免大量重复告警堆积
6. 重构告警等级判断逻辑：删除自定义极端温湿度阈值，严格按照实训文档规则分级，温湿度同时异常分开生成独立告警

### 3. 功能缺失补齐
1. 独立封装 `sort_alerts_by_severity` 告警排序函数，告警展示先按严重等级降序，同等级按时间倒序
2. 重命名扩容函数 expand_field_array，标准化数组自动扩容逻辑

### 4. 交互与文案优化
1. 修复按负责人搜索提示文案复制粘贴错误，提示文字与检索维度匹配
2. 菜单输入增加数字容错：非数字输入清空缓冲区，杜绝死循环
3. 菜单添加田块新增交互，移除硬编码测试数据，支持用户自定义录入田块信息
4. 统一函数、枚举命名规范：ALERT_LEVEL_x、pause_console、ts_to_time 语义清晰化

### 5. 内存安全优化
1. analyze_trend 定长数组越界风险修复，消除栈溢出隐患
2. 所有临时链表、复制节点使用后全部释放，全程无内存泄漏
3. 优化链表遍历删除指针逻辑，空指针判断全覆盖

## 四、已知遗留待优化点（实训拓展方向）
1. 持续异常告警未增加已解决标记，仅通过删除实现告警办结
2. 趋势分析当前采用固定数组存储，可优化为动态malloc数组适配超大记录量
3. 输入仅支持scanf整数读取，可拓展fgets支持带空格中文名称录入

## 五、编译运行说明
### 编译环境
Windows + Visual Studio / Dev-C++ / MinGW
依赖头文件：stdio.h,stdlib.h,string.h,time.h,math.h,windows.h

### 运行操作
1. 运行程序进入主菜单，数字选择对应功能
2. 新增田块后录入传感器数据，系统自动判定异常并生成告警
3. 数据统计模块可查看极值、趋势、异常记录
4. 告警模块统一查看、处理各类告警信息
5. 选择0退出系统，自动释放全部链表、数组内存，无内存泄漏

## 六、项目开发规范
1. 内存管理：所有malloc分配节点必须配套free，程序退出统一销毁全部资源
2. 字符串：全部使用安全_s系列函数，强制传入缓冲区长度参数
3. 常量阈值：全部使用宏定义，禁止代码内硬编码数字
4. 命名规范：结构体大驼峰，函数小驼峰，全局统一前缀区分
5. 错误处理：所有malloc、scanf、链表遍历均做空指针、返回值校验
